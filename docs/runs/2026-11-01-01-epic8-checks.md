**Observed.**

- **No question, and the want is not given (A to C, E to G).** The scene names a place and a role,
  so code asked nothing. Every confirmation showed `playersWant: [not given]`, every brief held
  `"playersWant": null`, and every writer's `[skill]` line named `not-given/playersWant.md`. No run
  had a fence or a forced Wall: the difficulty was rolled.
- **The hook came from the scene.** Every baker asks the party to catch the croissant thief. Where
  the scene leaves the thief open, run C keeps it as a gap, which the owner liked: it "doesn't force
  the party into a corner".
- **The control scene is unchanged (D).** It names all three fields, so no question and no
  not-given file. The death threat is the first lever, as in epic 7. Its difficulty was rolled
  (SomeWork) where epic 7's interviews inferred Wall.
- **Race (A to C).** The interviewer recorded `goblin baker` as one occupation, so the race die
  rolled human, human and dwarf, and the writer followed the brief. Owner: "we are not picking up the
  NPCs race from the situation given, which is a problem."
- **The race line fixed it (E to G).** The interviewer skill now says a people named with the role is
  two fields. All three runs recorded `race: goblin` and `occupation: baker` from the same words.
  Runs E and G never name the race in the text; F says "a goblin baker". None contradicts the scene.
- **Attitude came and went.** A to C recorded `furious` all three times, so save 8's "cheerfully
  oblivious" did not come back. E and G, with the race line, did not record it, and the dice rolled
  world-weary and condescending. Both writers still wrote him furious, because the scene is settled
  (ADR-008). E to G also stopped recording "someone keeps stealing his croissants" as
  `characterWants`, so the rolled twist (ADR-010 decision 5) now appears. Two seeds is too few to
  say whether the race line caused the attitude miss. If a later run misses it again, start at the
  interviewer skill's "Leaving a field out is never a mistake".
- **The owner on A to D:** "I really love the different outputs. The situations created, the
  personalities, the tone." Control: "really good and really useful for a DM."
