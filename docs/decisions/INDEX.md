# Decisions

Architecture decision records. Each is written once and never edited; when a decision changes, a new record supersedes it and the old one's status line says so. A hook enforces this. Until the "Decisions already made" table in `PLAN.md` is migrated, that table is the live list and this folder holds the ones recorded since.
