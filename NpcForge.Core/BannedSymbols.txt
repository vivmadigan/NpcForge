// What NpcForge.Core may not call (ADR-014, decision 7). Each line is a documentation comment ID, a
// semicolon and the door to use instead. The compiler turns a hit into error RS0030. Overloads are listed
// one by one because the format has no wildcard. Console.Error stays allowed: the core writes its traces there.
